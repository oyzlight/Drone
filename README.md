# 2025年全国大学生电子设计竞赛 H题 - 完整巡航、通信与识别系统

本项目为2025年电赛H题（基于ROS和PX4的无人机自主巡航系统）的完整源码。由 **23届seeker战队（小怪，雷总，源神）** 开发。

系统实现了在无GPS环境下的自主定位、动态路径规划（避开禁飞区）、全覆盖巡航、基于ONNX的目标检测识别分类以及多设备间的串口通信协调。

## 🌟 系统核心功能

1. **自主定位与控制**：接入Livox雷达的SLAM里程计数据，结合PX4飞控实现精准的 `OFFBOARD` 模式航点飞行与自动降落。
2. **动态路径规划**：基于7x9网格的BFS（广度优先搜索）算法，支持动态输入3个连续禁飞区，自动生成“弓”字形全覆盖路径及安全返航路径。
3. **机器视觉识别**：部署ONNX目标检测模型，实时矫正相机畸变，对目标（E, K, M, T, W类动物/标识）进行识别、置信度过滤、防抖计数计算。
4. **多机串口协同**：包含双串口通信节点，分别负责与任务系统/地面站进行数据交互（接收禁飞区、发送目标数量）以及与STM32下位机通信（控制LED状态指示）。

## 📂 节点文件结构与功能解析

整个系统被拆分为多个ROS Node，各司其职：

### 1. 飞行控制与规划 (`offboard.cpp`)

- **核心控制节点**：无人机的大脑。
- **主要功能**：
  - 订阅 `/tdata` 获取禁飞区坐标，利用内置的 BFS 算法进行路径规划。
  - 将 7x9 的网格逻辑坐标转换为实际的物理坐标（`x, y, z=0.9`）。
  - 管理 PX4 飞控状态，自动完成解锁 (Arm)、切换 `OFFBOARD` 模式。
  - 按顺序执行规划好的航点，到达目标后发送清理指令，任务完成后触发 `AUTO.LAND` 自动降落。

### 2. 视觉识别节点 (`cv_num_node.cpp`)

- **AI视觉节点**：负责目标检测。
- **主要功能**：
  - 使用 `OpenCV` 和 `ONNX Runtime` 加载 YOLO 格式的模型。
  - 实时读取 V4L2 摄像头数据，并根据标定参数（Camera Matrix 和 DistCoeffs）进行图像去畸变（Rectification）。
  - 识别 5 个类别 ("E", "K", "M", "T", "W")，只对设定的 ROI 区域内的目标进行处理。
  - **计数防抖逻辑**：连续识别 N 帧才确认计数，消失 M 帧后才允许重新计数，确保计数的准确性。
  - 计算目标偏离图像中心的像素误差 (`dxy`)。
![](.\f878c7c821832af4e4473f9121e0ed3e.jpg)
### 3. 里程计转换节点 (`livox_to_mavos.cpp`)

- **定位融合节点**：解决无GPS环境下的定位问题。
- **主要功能**：
  - 订阅来自 Mid360 (VINS 等 SLAM 算法) 的里程计数据 (`/Odometry`)。
  - 订阅 PX4 飞控的本地里程计 (`/mavros/local_position/odom`)。
  - 使用**滑动窗口滤波 (Sliding Window Average)** 计算雷达与飞控之间的初始 Yaw 角偏差。
  - 将雷达的坐标系转换对齐后，发布给 `/mavros/vision_pose/pose`，为飞控提供外部视觉定位数据。

### 4. 串口通信节点 (`serial_node.cpp` & `serial_stm32_node.cpp`)

- **`serial_node.cpp` (主串口)**：
  - 负责与外部任务设备交互（波特率 115200）。
  - 接收：起飞指令、禁飞区坐标 (`xy0, xy1, xy2`)。
  - 发送：地图初始化状态、规划好的全量航点、识别到的动物数量 (`wild_msgs`)。
- **`serial_stm32_node.cpp` (STM32串口)**：
  - 负责与机载 STM32 交互，控制声光外设。
  - 根据当前飞行状态 (`Fly_state`) 和识别状态 (`Detect_animals`)，向 STM32 发送指令控制 LED 常亮或闪烁。

### 5. 算法验证与测试工具 (`lj.cpp` & `test.cpp`)

- **`lj.cpp`**：独立的 BFS 路径规划纯 C++ 测试文件，在终端中以文本可视化形式打印 7x9 网格的绕行路径，用于验证算法逻辑。
- **`test.cpp`**：早期的 Offboard 模式测试代码，包含硬编码的测试航点。

## 🚀 核心算法亮点

### 动态路径覆盖与安全返航 (BFS规划)

当收到三个禁飞区坐标时，系统不会使用死板的预设航线，而是：

1. **策略选择**：判断禁飞区是横向连续还是纵向连续，决定采用“行优先 (fly_row_strategy)”还是“列优先 (fly_col_strategy)”的“弓”字形扫描策略。
2. **合法性校验**：所有途径点必须经过 `isValid()` 校验，确保不进入禁飞区且不越界。
3. **安全返航**：到达覆盖终点后，再次调用 BFS 算法 (`computeReturnPath`) 搜索一条避开禁飞区回到起点 (6,8) 的最短路径，并提取路径的**转折点** (`simplifyPath`) 以简化航点数量，提高返航效率。

### 视觉防抖与去畸变机制

1. 相对于直接将图像送入模型，程序预先计算了 `map1` 和 `map2` 映射表，利用 `cv::remap` 实现**零延迟的硬件级图像去畸变**。
2. 维护了四个字典（连续出现次数、丢失次数、总计数、已计数集合），完美解决了无人机在悬停或轻微晃动时导致的目标重复计数问题。
