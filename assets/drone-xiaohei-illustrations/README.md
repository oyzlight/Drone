# Drone Xiaohei Illustrations

这组图片是为 Drone 项目 README 生成的 16:9 小黑风格正文配图，用来解释项目里的几个关键系统动作。

| 文件 | 对应内容 |
| --- | --- |
| `01-gps-free-localization.png` | 无 GPS 环境下的雷达里程计与 PX4 位姿对齐 |
| `02-bfs-coverage-return.png` | 7x9 网格、禁飞区绕行、弓字巡航与安全返航 |
| `03-vision-undistort-counting.png` | 图像去畸变、ROI 过滤、连续帧防重复计数 |
| `04-serial-coordination-led.png` | 主串口、STM32、LED 状态与任务指令协同 |

生成规则：纯白背景、黑色手绘线稿、小黑参与核心动作、少量红/橙/蓝中文批注，避免正式流程图或 PPT 信息图风格。
